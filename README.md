# Xưởng Video — bản tải cho Mac

App làm video quảng cáo bán hàng từ kho clip: nạp thông tin sản phẩm, cắt clip, viết kịch bản, đọc giọng, dựng video hàng loạt.

### 👉 [Tải bản mới nhất](https://github.com/chuongprocreate-lang/xuong-video/releases/latest)

Vào trang trên, bấm **`XuongVideo-Mac.zip`** để tải. Cách cài ghi ngay trong trang tải.

- Chạy trên Mac chip Apple (M1 trở lên), macOS 14 trở lên.
- Máy mới phải được Sếp duyệt mới dùng được.
- Cài rồi thì app tự báo bản mới — không cần quay lại đây tải.

Kho này chỉ chứa bản cài app. Hai dòng **Source code** GitHub tự thêm ở cuối trang tải chỉ có đúng file giới thiệu này, không cần tải.
